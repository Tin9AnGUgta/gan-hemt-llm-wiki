# 公開與權利檢查

原始 PDF 預設不公開。論文是否已公開、內容是否保密、圖表及素材的使用依據均須查證；引用不是授權。

公開白名單 `public-files.json` 僅允許逐一列入的檔案。新增公開檔案前檢查來源、寫作方式與公開範圍；未知素材先排除。機械檢查不能自行判定合理使用或保證著作權合法性。

## 發布前必要項目

- 無 PDF、抽取全文、原始圖表、私人路徑、憑證及保密研究。
- 文字為自行組織教學內容，非大篇幅複製或近似改寫。
- 自製圖依原理重新設計；第三方素材有清楚來源及使用依據。
- 未公開或保密的研究結果不因轉述而公開。
- 列出每一項仍需人工確認的素材；有未決項時排除相關內容或停止發布。
- 公開紀錄只有檢查摘要與定位，不包含未授權來源全文。

## 目前仍需確認

五篇論文的正式公開書目、內容公開範圍與原圖使用依據尚未確認。因此初始 Repo 只發布專案自寫的規範、模板、工具及中繼資料，不發布論文研究細節。
